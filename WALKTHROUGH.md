# Руководство администратора: Развертывание автономного CTF-сервера (mvsosh)

В этом документе содержится детальная пошаговая инструкция по подготовке, конфигурированию и тестированию инфраструктуры для проведения оффлайн CTF соревнований.

---

## 1. Подготовка виртуальной машины сервера (Debian 13)

### Конфигурация виртуальной машины VirtualBox для сервера:
- **ОС:** Debian 13 (64-bit).
- **Процессор:** от 4 vCPU.
- **Оперативная память:** от 4 до 8 ГБ.
- **Диск:** 40+ ГБ.
- **Сетевой адаптер 1:** **NAT** (интерфейс `eth0` или `enp0s3`) — для выхода в интернет во время подготовки (скачивание пакетов и образов).
- **Сетевой адаптер 2:** **Внутренняя сеть (Internal Network)** (интерфейс `enp0s8` или `eth0` в зависимости от среды) с именем **`mvsosh-net`** — для подключения машин участников (Kali Linux). Неразборчивый режим (Promiscuous Mode): **Разрешить всё**.

> **Важно:** Сеть участников привязывается к интерфейсу лабы (`enp0s8` или `eth0`). На нем настраивается статический IP `192.168.100.1` и запускается DHCP-сервер. Адаптер NAT остается для доступа в интернет во время подготовки и отключается в день соревнований.

---

## 2. Развертывание платформы (этап с интернетом)

### Шаг 2.1. Подготовка каталога
```bash
sudo su -
mkdir -p /opt/mvsosh/CTFd-compose
cd /opt/mvsosh/CTFd-compose
# Клонирование или копирование проекта в рабочий каталог
```

### Шаг 2.2. Запуск базовой настройки
Скрипт `scripts/setup-host.sh` принимает имя сетевого адаптера для участников (или определяет его автоматически):
```bash
chmod +x scripts/*.sh
./scripts/setup-host.sh enp0s8
```

Скрипт автоматически:
1. Выберет интерфейс участников (например, `enp0s8` или `eth0`).
2. Проверит и остановит системные `apache2` / `nginx`, освобождая порты.
3. Установит Docker, Docker Compose v2, `dnsmasq` и необходимые утилиты.
4. Пропишет постоянную конфигурацию статического IP `192.168.100.1` в `/etc/network/interfaces.d/mvsosh-lab.cfg` и поднимет интерфейс.
5. Настроит `/etc/dnsmasq.d/mvsosh-lab.conf` для выдачи IP участникам (`192.168.100.100-200`) и разрешения доменов `mvsosh.local` и `ctf.local`.
6. Инициализирует Docker Swarm и создаст overlay-сеть `ctfd-compose_frp_containers`.
7. Соберет локальные образы `ctfd-whale-local`, `local-frp` и тестовое задание `mvsosh/test-web:latest`.
8. Настроит скрипт `/usr/local/bin/ctfd-up.sh` и системный юнит `ctfd-compose.service` для автозапуска при загрузке ОС.

## 3. Проверка сервисов и доступность

1. Проверьте статус сервиса:
   ```bash
   systemctl status ctfd-compose.service
   ```
2. Откройте в браузере:
   - `http://mvsosh.local:8000` (или `http://192.168.100.1:8000`)
   - Домен `http://ctf.local:8000` также поддерживается как алиас.

3. Заполните первоначальный мастер настройки CTFd (CTF name, admin user/password).

---

## 4. Конфигурация плагина CTFd-Whale

1. Перейдите в **Admin Panel** -> вкладка **Whale**:
   - **Docker Swarm Nodes**: `linux-1`
   - **Docker API URL**: `unix:///var/run/docker.sock`
   - **Auto Connect Network**: `ctfd-compose_frp_containers`
   - **FRP API URL**: `http://frpc:7400`
   - **FRP Direct IP Address**: `192.168.100.1`
   - **FRP Direct Port Minimum / Maximum**: `21000` - `22000`
   - **FRP Http Domain Suffix**: `mvsosh.local`
   - **FRP Http Port**: `8000`
2. Нажмите **Update**.

---

## 5. Создание динамического задания в CTFd

1. В Admin Panel перейдите в **Challenges** -> **+** (New Challenge).
2. Выберите тип: **`dynamic_docker`**.
3. Заполните поля:
   - **Name**: `Warmup Web Challenge`.
   - **Category**: `Web`.
   - **Docker Image**: `mvsosh/test-web:latest` (также доступен тег `ctf/test-web:latest`).
   - **Frp Redirect Type**: `Direct`.
   - **Redirect Port**: `80`.
   - **Dynamic Flag**: включить.
4. Нажмите **Create**.

---

## 6. Проверка оффлайн-готовности (День соревнований)

1. Отключите сетевой кабель на Адаптере NAT в свойствах VirtualBox.
2. Запустите проверку:
   ```bash
   ./scripts/verify-offline.sh
   ```

---

## 7. Инструкция для участников (Kali Linux)

1. **В настройках VirtualBox ВМ Kali Linux:**
   - Сеть -> Адаптер 1:
   - Тип подключения: **Внутренняя сеть (Internal Network)**.
   - Имя сети: **`mvsosh-net`**.
   - Неразборчивый режим: **Разрешить виртуальным машинам** или **Разрешить всё**.

2. **Запуск:**
   - Запустите ВМ Kali Linux.
   - В терминале Kali убедитесь в получении адреса:
     ```bash
     ip addr show
     # Должен появиться адрес из диапазона 192.168.100.100-200
     ping -c 2 mvsosh.local
     ```
   - Откройте браузер и перейдите на **`http://mvsosh.local:8000`** (обязательно указывайте порт `:8000`).
